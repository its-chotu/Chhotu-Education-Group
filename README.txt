# Chhotu Education Group Website Code

Is folder me aapki portal website ke saare files separate hain:

1. `index.html` - Main HTML Structure & Layout
2. `style.css` - Dark Theme Styling matching Shivanshprep Screenshot
3. `script.js` - Interactive Test System & Local Video/PDF Upload Logic

## Website Kaise Chalayein:
1. Saare files ko ek hi folder me save karein.
2. `index.html` par double click karke kisi bhi web browser (Chrome, Edge, Firefox) me kholein.
3. Learn & Media section se aap apne system se videos aur PDFs upload karke stream/view kar sakte hain.
